# WorkflowBuilder

WorkflowBuilder lets you design a versioned **Blueprint**, start a **Process** from it, and inspect the inputs, outputs and status of each **Step**. A Plugin supplies a reusable task. A Phase Series connects Blueprints so that one phase can pass data to the next.

**New to the platform?** Build a one-Step Blueprint, start it with two numbers and verify its output in Process Explorer. The walkthrough covers the local Aspire services, Angular UI and Plugin bundle you need. [Run your first Process](Docs/tutorials/first-process.md)
